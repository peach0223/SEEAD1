# Structuring End-to-End Autonomous Driving: A BEV-Centric Framework with Diffusion-Based Feature Enhancement and Optimal Response Ratio Planning

To address redundant perception features, degraded BEV representations, and limited trajectory scoring, SEEAD extends [TransFuser](https://github.com/autonomousvision/transfuser) with variational information bottleneck (VIB) compression, diffusion-based BEV feature enhancement, and Optimal Response Ratio Planning (ORRP). These components filter irrelevant information, improve feature robustness, and balance control cost with driving reward, enabling more stable and efficient end-to-end driving.
